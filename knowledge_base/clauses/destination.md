# 交付目的地与接收方白名单

1. 数据仅可交付至登记在册的香港跨境空间连接器（示意名单：hk-crossborder-connector-1）。
2. 交付目的地必须位于香港区域。向其他区域交付一律拒绝。
3. 最终接收方须在白名单内（示意名单：hk-insurance-co-a）。
4. 跨境空间节点接收加密数据后不得中途解密或扩大数据范围，仅按授权结果交付。

> 名单为业务/法律假设的示意值，实际以正式合规评审为准。
