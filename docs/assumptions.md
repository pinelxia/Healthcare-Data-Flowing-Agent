# 法律假设、业务假设与系统边界

> 本文档按项目要求明确标注所有假设。**本项目不提供正式法律意见**，全部规则、条款与名单均为演示用示意内容。

## 1. 法律假设（明确：非法律意见）

| # | 假设 | 说明 |
|---|------|------|
| L1 | 跨境数据流通需经审批与最小化 | 参照《数据安全法》《个人信息保护法》及香港《个人资料（私隐）条例》的**一般框架精神**示意；未做任何正式法律分析 |
| L2 | 敏感就诊数据需患者授权 | 假设诊断类数据须取得患者授权同意记录方可交付（示意，具体以实际法律意见为准） |
| L3 | 数据出境有目的地限制 | 假设仅允许交付至香港侧登记连接器（示意） |
| L4 | 保存期限有上限 | 假设上限 180 天（示意值，可配置） |

## 2. 业务假设

| # | 假设 | 值 |

## 3. 系统边界

- **Mock 优先**：医院/保险/数据空间连接器均为 Mock；知识库条款与策略为示意内容。
- **不处理真实数据**：本组件只消费结构化申请与证据标记（`present/ref`），不接触真实病历或个人信息。
- **判定边界**：LLM（DeepSeek）只做检索排序、条款归纳、缺失提示与解释；**verdict 字段只由确定性引擎写入**，代码层面强制。
- **传输边界**：本组件不负责实际数据交付与加密（属跨境空间/医院连接器职责），仅输出是否允许交付的判定。
- **版本边界**：策略带版本号；申请可指定期望版本，缺失时报错，不静默回退到其他版本。
